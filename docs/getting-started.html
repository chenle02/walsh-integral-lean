Build and use

This source version uses Lean leanprover/lean4:v4.35.0 and Mathlib 56a005855ea17e0b0958f73ec801ae140b0a1679. Keep the toolchain and manifest together.

The following URLs define the public dependency interface. Select a published version tag or exact commit from the repository verification record; a source API version alone does not certify a tag exists.

git clone https://github.com/chenle02/walsh-integral-lean.git
cd walsh-integral-lean
lake exe cache get
lake build

Use import WalshIntegral, or a narrower module from the API index.

Use as a Lake dependency

Use the same Lean toolchain. The version-tag spelling is shown below; verify the chosen tag or replace it with the exact source commit you need:

[[require]]
name = "WalshIntegral"
git = "https://github.com/chenle02/walsh-integral-lean.git"
rev = "v0.8.0"

Then run lake update WalshIntegral in your downstream project and build it. Never update dependency pins inside a frozen verification replay.

Verification is separate

A normal build elaborates the source. The verification contract also requires complete ownership and axiom checks, strict negative controls, independent comparison and native kernel replay. Follow the versioned source instructions; the README verification block records actual evidence.
